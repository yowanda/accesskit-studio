# Sample brief — Free Coding Class for Teens

Use this to test AccessKit Studio (it's also the pre-loaded default in the app).

- **Campaign name:** Free Coding Class for Teens
- **Organization type:** Nonprofit
- **Audience:** Teenagers aged 13–18 and their parents
- **Key message:** Free weekend coding classes for teenagers. No experience needed, laptops provided, everyone is welcome.
- **Goal:** Sign-ups / registrations
- **Tone:** Warm & encouraging
- **Call to action:** Sign up free at example.org/code
- **Poster colors:** background #0f766e, text #ffffff (WCAG AA: 5.47:1)

Expected result: a full kit scoring ~86/100, with the audit passing contrast, reading level, alt text, hashtags, emoji, captions, and plain-language checks.
